# Приборы по ESP-NOW — что голова принимает

Голова слушает эфир ESP-NOW и, как только видит поток, умеет показать тахометр и температуру двигателя.
Передатчик — любой ESP32: свой CAN / OBD-адаптер, датчик, что угодно. Голова никому не отвечает и ничего не адресует.

Готовый пример: [examples/espnow_sender](examples/espnow_sender) — шлёт обороты и температуру по синусу, чтобы проверить на столе.

## Эфир

- **Канал Wi-Fi 1**, широковещательно (`FF:FF:FF:FF:FF:FF`), без шифрования
- Голова слушает канал 1, когда **не подключена** к домашнему Wi-Fi (автономный режим, машина). В домашнем Wi-Fi — только если роутер на канале 1
- Little-endian, структуры упакованы (`__attribute__((packed))`)

## Пакеты

Каждый пакет начинается с заголовка (7 байт):

```c
typedef struct __attribute__((packed)) {
  uint8_t  magic;   // 0x4D ('M') — чужое голова отбрасывает
  uint8_t  type;    // 1 — значения, 2 — подписи
  uint8_t  count;   // сколько элементов дальше
  uint32_t seq;     // счётчик пакетов
} MsgHead;
```

### Значения — `type = 1`

`MsgHead` + `count` × 5 байт:

```c
typedef struct __attribute__((packed)) {
  uint8_t id;       // номер сигнала, см. таблицу
  int32_t val;      // значение × 10^dec (dec — из подписи; для таблицы ниже dec = 0)
} SigValue;
```

Слать **часто** (у мозга MONSTRIX — 50 раз в секунду). Значение старше **3 с** голова считает пропавшим. Пакеты есть последние 3 с — «в машине».

### Подписи — `type = 2` (по желанию)

`MsgHead` + `count` × 27 байт, до 8 штук в пакете, раз в 0,5 с по кругу:

```c
typedef struct __attribute__((packed)) {
  uint8_t id;
  char    name[10];   // "RPM", "COOLANT"
  char    unit[6];    // "rpm", "C", "km/h"
  uint8_t dec;        // знаков после запятой у val
  uint8_t src;        // 0 — с шины, 1 — из OBD
  int32_t vmin, vmax; // диапазон шкалы (в единицах val)
} SigName;
```

Без подписей голова считает `dec = 0`.

## Что голова показывает

| id | Сигнал | Единицы | Где |
|---|---|---|---|
| 100 | обороты | об/мин | тахометр 0–7000 (красная зона с 6000) |
| 101 | скорость | км/ч | на тахометре справа внизу |
| 102 | температура ОЖ | °C | шкала 40–120: синий < 50, бирюзовый < 70, зелёный < 105, красный |
| 103 | передача | 0–6 | на тахометре слева внизу (другие значения не показывает) |
| 106 | кондиционер | 0 / 1 | только в снимок ассистенту |

Остальные id голова пропускает. Средняя кнопка листает: глаза → тахометр → температура → глаза.

## Минимальный пакет

Обороты 850 и температура 64:

```
4D 01 02 01 00 00 00 | 64 52 03 00 00 | 66 40 00 00 00
magic type count seq    id=100 val=850   id=102 val=64
```
