# API головы — свой сервер для режима ассистента

Голова ходит на **твой** сервер по HTTPS. Адрес и токен — на странице настроек головы (`http://monstrik.local`).
Сервер распознаёт речь, решает, что ответить, озвучивает — голова только слушает, играет и рисует.

Все запросы с заголовком `X-Device-Token: <токен>`. Пути — от адреса сервера (`https://my-server.example/api/v1/...`).

## Разговор — `POST /api/v1/device/talk`

Голова записала фразу (нажал кнопку, замолчал) и отправляет.

Запрос:
- тело — **PCM 16 бит, моно, 16 кГц**, `Content-Type: application/octet-stream`
- `X-Capture-Id` — уникальный id записи (повтор с тем же id — не дублировать)

Ответ `200`:
- тело — **звук ответа**: PCM 16 бит, моно, 16 кГц (`Content-Type: audio/L16; rate=16000; channels=1`), `Content-Length` обязателен. Голова начинает играть, как придут первые ~0,4 с
- заголовки:

| Заголовок | Что | Пример |
|---|---|---|
| `X-Emotion` | лицо на время ответа | `happy` · `thinking` · `surprised` · `sad` · `angry` · `sleepy` · `cool` · `worried` (другое — `happy`) |
| `X-Kind` | что это было | `record` (записал) · `answer` · `car` · `brief` |
| `X-Fx` | вспышка, по желанию | `levelup` · `sweat` · `sparkle` · `rage` · `love` · `impact` · `speed` · `anime` · … (незнакомое — пропустить) |
| `X-Say` | что сказано, UTF-8 в percent-encoding | `%D0%9F%D1%80...` — показывается, только если звука нет |
| `X-Tts` | `failed` — звук не получился | тело пустое, голова покажет `X-Say` текстом |
| `X-Look` | версия «вида» (см. ниже) | сменилась — голова перечитает вид |

Ошибки — JSON `{"error": "текст"}`: `401` токен, `402` лимит, `422` не расслышал, `429` часто (`Retry-After`), `5xx`. Голова покажет грустное лицо и строку.

Голова сама: показывает вспышку не чаще раза в минуту (`sparkle / rage / love / anime` — раз в 10 мин), `levelup` — первую за 12 ч всегда.

## Сводка — `GET /api/v1/device/brief`

Нижняя кнопка. Ответ — как у `talk`. `?reason=enter` — голова сама заговорила (сел в машину, см. телеметрию).

## Дела на сегодня — `GET /api/v1/device/today`

Бегут строкой внизу, пока голова говорит ответ `X-Kind: brief` или `record`.

```json
{"label": "пт, 14 ноября", "items": [{"time": "10:00", "title": "Встреча"}, {"time": null, "title": "Купить хлеб"}], "more": 3}
```

`ETag` + `If-None-Match` → `304`, если не менялось.

## Заполнители и вид — `GET /api/v1/device/fillers`

Короткие фразы «щас гляну», которые голова говорит сразу после кнопки, пока сервер думает, и «вид».

```json
{
  "version": "bc3733d2d4bc",
  "clips": [{"id": "8d5f9380e0451fba", "text": "Так, щас гляну.", "seconds": 0.8, "bytes": 26000}],
  "pending": 0,
  "look": {"main": "#ff6b35", "a": "#27e0ff", "b": "#ff3d9a", "crt": true, "flashes": true, "version": "1e3e5b86"}
}
```

- `GET /api/v1/device/fillers?id=<id>` — звук фразы, PCM 16 бит моно 16 кГц
- `version` сменилась — голова перекачивает фразы; `pending > 0` — спросит снова через минуту
- `look`: `main` — цвет лица, `a`, `b` — акценты вспышек, `crt` — полосы старого монитора, `flashes` — вспышки вкл/выкл

## Машина — `POST /api/v1/device/telemetry`

Если голова видит поток ESP-NOW ([PROTOCOL-ESPNOW.md](PROTOCOL-ESPNOW.md)), шлёт снимок раз в 30 с и при посадке:

```json
{"coolant": 64, "rpm": 850, "engineOn": true, "speed": 0, "gear": 1, "ac": false}
```

Ответ `{"announce": true}` — голова сама позовёт `brief?reason=enter` и заговорит. Можно отвечать `{}`.
